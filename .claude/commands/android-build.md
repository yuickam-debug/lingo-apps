description: Build an app and sync it to the Android project
argument-hint: da | de | both
---

Prepare the Android build for: $ARGUMENTS (default: da)

From the `lingo-apps/` root run `npm run sync:da` (DALingo) and/or `npm run sync:de` (DELingo).

If the build fails, explain the error in plain language, fix it, and rerun.
When sync succeeds, tell me: "Ready — open packages/<app>/android in Android Studio and press Run."
Do not open Android Studio or run Gradle yourself.
